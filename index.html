Same-name conflict detection

The problem phone deduplication
can't solve.

Phone and email deduplication catches exact re-entries. It doesn't catch the harder problem: the same name appearing multiple times with different contact details.

This pipeline detects every same-name group and scores each pair using business logic — not fuzzy string matching. The scorer looks at area codes, budget proximity, source labels, and Florida metro geography together.

Every pair gets a verdict and a written explanation. The agent opens the ⚠ Name Conflicts tab, reads the reasoning, and makes the call: Merge, Keep Both, or Discard.

🔴 Likely Duplicate

Same area code (+3) and one entry missing email (+2). Score ≥ 4. Recommend merging — almost certainly the same person entered twice from different sources.

🟡 Possible Duplicate

Partial overlap — same source, similar budget, or one incomplete entry. Score 1–3. Agent makes the final call.

🟢 Probably Different

Different FL metros (Tampa vs Jacksonville = −2). Score ≤ 0. Treat as separate leads — the geography says they're different people.
